# Contributing

Please keep changes within the project's scope (see [NOTICE.md](NOTICE.md)): a client mod and launcher, with no
game files and no tools to decrypt, unpack, or circumvent the protection of any game.

Pull requests that add such tooling, or that include game assets, keys, or other copyrighted content, will be
declined. Research is welcome as code and comments; game-derived data is regenerated from your own client by the
scripts in `tools/data`, never committed.
